# Especial Sobremesas Natalinas — Página de vendas

Página de vendas da Keylla (Família Brigadier).

## Arquivos
- `index.html` — a página (HTML, CSS e JS no mesmo arquivo)
- `img/` — fotos das sobremesas e da professora

## Publicar no GitHub Pages
1. Crie um repositório e envie o conteúdo desta pasta (o `index.html` precisa ficar na raiz).
2. No repositório, vá em **Settings › Pages**.
3. Em **Source**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)` e salve.
4. Em alguns minutos a página fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Depois de publicar
No `index.html`, troque `[URL_DA_PAGINA]` (nas tags `og:url` e `og:image`) pelo endereço da página publicada.
